# No AI Slop CN版

一个面向中文写作的Agent Skill：识别并处理 40 多种空泛、虚高、模板化或机械表达，同时尽量保留作者原有的写作风格和内容。

本项目基于 Peter Yang 的 [no-ai-slop](https://github.com/petergyang/no-ai-slop) 改编，并结合中文语言写作规范及多个开源项目重新设计。新增了公文套话、四字词堆叠、万能升华、排比过载、短视频钩子、中英术语装饰、段落同构、名词化、指代漂移等中文高发模式。

## 它会处理什么

| 模式 | 常见写法 |
|---|---|
| 二元对立 | “这不是一次更新，而是一场革命。” |
| 清嗓式开场 | “不得不说，在当今这个时代……” |
| 伪洞察铺垫 | “很多人没有意识到，真正重要的是……” |
| 冒号揭晓 | “答案其实很简单：坚持。” |
| 悬浮分析 | “彰显了团队对创新的不懈追求。” |
| 重要性吹捧 | “具有里程碑式意义。” |
| 模糊归因 | “有研究表明”“业内人士普遍认为” |
| 假强动词 | “赋能业务”“助力增长”“打造闭环” |
| 四字词堆叠 | “全面布局、持续深耕、协同发力” |
| 公文套话 | “在……背景下”“进一步统一思想” |
| 万能升华 | 从具体小事突然上升到时代、未来或人类 |
| 机械排比 | 连续三段相同句式，信息却没有递进 |
| 短视频钩子 | “你敢相信吗？”“看完你就懂了” |
| 中英术语装饰 | “形成完整的闭环（closed loop）” |


## 安装

把下面这句话粘贴到 Cursor、Claude Code、Codex 或其他支持智能体技能的工具中：

```text
请将这个技能安装到全局：https://github.com/qCanoe/no-ai-slop-cn
```

也可以把整个仓库放入工具支持的技能目录。最少需要保留 `SKILL.md`、`eval.md`、`tests.md` 和 `agents/openai.yaml`，并维持相对路径不变。

## 使用

### 1. 编辑草稿

粘贴草稿并调用：

```text
/no-ai-slop-cn

[你的草稿]
```

该技能会返回完整修改稿和简短的“修改说明”。它只做必要修改，并在输出前按 `eval.md` 自检。

默认使用标准档。你也可以明确要求：

- “只改明显问题，尽量保留原句”：轻度编辑。
- “允许重组结构，彻底清理模板感”：深度编辑。

### 2. 只检测 AI 腔表达

```text
/no-ai-slop-cn 检查这段文字有哪些 AI 表达，不要改写

[待检查文本]
```

该技能会逐项列出命中的模式、引用原句，并给出简短修改方向。

## 文件

1. `SKILL.md`：中文编辑规则、检测模式和工作流。
2. `eval.md`：技能对编辑结果执行的通过/失败检查。
3. `tests.md`：30 个覆盖场景和 8 个固定回归样例。
4. `.codex-plugin/plugin.json`：ChatGPT 和 Codex 插件元数据。
5. `scripts/build_plugin.py`：从规范源文件构建并校验插件压缩包。
